# OddViewer

Kalshi hedge scanner MVP focused on:

- Synthetic NO
- Favorite Fade
- Double Chance

Features:
- Load Kalshi markets from public API
- Filter by keyword and price
- Select YES/NO contracts
- Outcome-by-outcome P/L calculator
- Suggestion engine for hedge structures

Kalshi API:
https://external-api.kalshi.com/trade-api/v2
